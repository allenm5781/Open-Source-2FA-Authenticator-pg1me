## Overview

**Aegis Authenticator** — A secure, encrypted TOTP two-factor authentication app. It runs on **Android** and is distributed under the **GPL-3.0** license.

If you searched for *"aegis authenticator download"*, this is the tool you are looking for. Below you will find a feature breakdown, platform-by-platform installation instructions, a quick-start example, and answers to the most common questions.

## Key Features

- Encrypted local vault
- TOTP and HOTP support
- Encrypted backups and export
- Organize with groups and icons
- Biometric unlock
- Open source
